# Simuleringar för Syna

Python-skript som användes för att stämma av reglerna. De körs inte av spelet.

- `sim.py` – den första poängregeln (bud = poäng) och varför den ströks.
- `duel.py` – duellpoängen: jämvikt i budgivningen och när det lönar sig att syna.
- `schema.py` – schemaläggaren som förlaga till `../schedule.js`.

Kör med `python3 duel.py` (kräver numpy för `sim.py` och `duel.py`).
